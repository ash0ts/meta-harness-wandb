# Live early-stopping comparison

Decision: can an AI engineer avoid redundant inference calls without paying an unacceptable latency or quality penalty? This is a prospective operational comparison on previously inspected tasks, not a new holdout or optimizer result.

Freeze the request bytes from engineering E's large-context sample 1, native answer extractor, native scorer, source identities and targets. Source upstream commit f805ad3aa4ada290458c1e0deadbe132fbbdea4e; E manifest fbd8e9edfb8172d0c19a2d2bc9de151dfab6b16afe32d49e4d3d212508c749a0. The contract binds all runtime and telemetry Python files by SHA-256. It includes a deterministic schedule and private input-pack hash. Preparation verifies all pinned files and every task against its released source record. There is no proposer or changed model weight.

Compare five concurrent calls against three concurrent calls followed by two only if the first three successful nonempty normalized labels disagree. A transport-exhausted first batch fails the policy without more calls. Empty extracted labels continue to five. Plurality chooses the earliest sample among tied normalized labels, then the selected original answer is graded. Selection never reads the target.

Membership: 100 USPTO, 212 Symptom2Disease and 100 LawBench tasks; two temperatures (0 primary, 1 supporting), two repeats, two policies = 3,296 decisions. Fresh sample identities prevent response reuse across tasks, arms, repeats, temperatures and positions. No model API seed. The fixed large-context scaffold, max_tokens=16,384, model openai/gpt-oss-120b, and Forge endpoint remain as in E. Diagnostic smoke uses index 0 in each dataset in a separate campaign and is excluded from measured results.

Execution: four admitted task workers, shared twenty-call pool, one policy block at a time. Shuffle tasks into blocks of at most sixteen; pair policies on identical block membership and randomize their order, then randomize pair order (seed 20261112). This closed-loop workload is not an arrival-rate production load test. Reviewed fixed host Python directly calls the metered gateway; there is no cloud sandbox or worker filesystem/network isolation claim. Export happens outside measured policy execution. Credentials use the explicit one-use FD mechanism.

Measures: native exact-label quality is correct policies / all assigned decisions within each dataset, then equal dataset macro averaging across the two repeats; transport failures score zero and have a separate failure count. Cost is recorded provider usage at frozen prices (input $0.03/M, output $0.17/M) plus a separate upper bound for every missing-usage attempt. No invoice, local compute, or telemetry cost claim. Calls count logical samples, retries count separately. Latency is task-worker admission through answer selection, including durable start recording, request creation, job registration, gateway wait, retries and conditional second batch; excluding waiting for a task-worker slot, grading, post-selection persistence, and export. Report p50/p95 across task occurrences, by policy, temperature and dataset. Keep interrupted policies in quality; their latency is unavailable. Never replay completed responses as new timed work. Resume skips completed decisions, marks started unfinished ones interrupted, and only launches unstarted decisions.

Heartbeat once per second flags intervals longer than 10s or wall/monotonic disagreement over 5s. Report all latency and a sensitivity excluding overlapping decisions; do not trim slow service responses. Caffeinate prevents idle/system sleep while running, without keeping the display awake. No causal claim about provider latency or host gap causes.

Primary quality comparison: paired difference at temperature zero, task bootstrap within dataset, keeping both repeats together; 10,000 resamples, seed 20261113 (plus temperature). Conditional 95% percentile interval, no multiplicity adjustment. Temperature one is supporting evidence. Same-output audit reconstructs the conditional policy from every complete fixed-five set and must preserve selected original sample exactly. This deterministic property does not imply live independent-arm equivalence or correctness of agreeing answers. Do not tune stopping thresholds or select favorable subsets after inspection.

Budget: protective $50 inference cap, $35 controls and $5 recovery, remaining phases small reserves; expected roughly $7 from E usage. Preserve all retries and failures. Stop on source/runtime drift, unproven cleanup, policy invariant violation, or budget halt. Existing gateway bounded retries and circuit breaker remain fixed. Full cost accounting covers all attempts; smoke separate.

Forge: private wandb/mh-forge-preflight-20261110 project. One hash-only Agent Lens conversation per completed block, a turn per policy decision and one LLM span per logical call; retain provider attempt counts and native usage availability. Export through existing scan, budget, idempotent receipts and readback. W&B numeric study table has one row per decision, with native metrics/config lineage readback. No dataset prompts, targets, answer labels, raw replies or credentials in public exports. Public answer classes are local ordinal classes sufficient to reconstruct the vote; private evidence permits native regrading. No remote article publishing authorized.
