# Harness controls: calculation download

Run `python3 reproduce.py` in this directory. Only the Python standard library is required; no network calls or model requests are made.

`test-scores.csv` contains the same 412 paired test outcomes. `task` is a one-based ordinal inside the fixed evaluation order; it is not a source-dataset ID. `overlap` marks the one exact validation/test overlap. Columns record native scorer outcomes, not semantic validity. `correct_samples` and `vote_count` are retained measurements from the five saved outputs. Their derivation requires the protected outputs; this download can recompute their aggregates but cannot independently regrade answers.

`validation-scores.csv` contains five repeats of 130 tasks under two baselines (1,300 rows). `normalized_label_changed` and `identical_requests` are verified measurements from the protected request/output audit; no request or label hashes are included here.

The script uses the same paired stratified bootstrap as the saved analysis: 10,000 draws, seed 20261110, equal dataset weights, percentile interval with linear interpolation. The intervals condition on the fixed datasets and saved model outputs. They exclude model resampling and search uncertainty.

`aggregates.json` preserves cost scopes and the secondary comparison with the first temperature-one sample. Prices were frozen at $0.03 per million input tokens (including cache) and $0.17 per million output tokens. Costs are marginal test inference estimates, not invoices or total project spending. Complete usage and bounded unknowns remain separate.

These files contain no raw task text, target labels, responses, private traces, credentials or filesystem locations. Full source records, exact scorer versions, host regrading, telemetry readbacks and failed attempts are retained privately. No new inference or scoring was performed to create the download.

## Common-prompt engineering follow-up

The same command also runs `reproduce_engineering.py`. `engineering-scores.csv` contains 8,240 outcomes: 412 tasks × four arms × five fresh draws. `index` is a zero-based evaluation ordinal, not a dataset source ID. `label_class` is assigned in first-occurrence order separately within each task and arm. Its only meaning is whether two of that group's five normalized answers match; it does not identify any answer. This permits reproduction of 1/3/5-answer plurality selection without disclosing the predictions. Earliest sample breaks a tied plurality. `strict_json_valid` requires a whole-response JSON object with a string final_answer; it is a format diagnostic, separate from native correctness. `examples` and `example_chars` record the actual capped context, not the nominal pool size.

The context comparison averages each task's five correctness outcomes. The sampling comparison uses the first 1, 3 or 5 saved outputs at a fixed temperature; it never selects the best draw by accuracy. Primary temperature is zero; full-context temperature one is supporting evidence. Task bootstrap: 10,000 paired resamples within datasets, seed 20261111, keep all five draws of a task together; empirical order statistics at indices 250 and 9750. This differs from the earlier study's interpolation convention. Intervals condition on these saved outputs, do not quantify future model reruns or search uncertainty, and are not adjusted for multiple comparisons. The one known Symptom2Disease overlap (evaluation ordinal 11) is removed only in the separate sensitivity analysis.

`engineering-costs.csv` retains a numeric-only row for every new campaign provider attempt, including failures, with no call identifiers or content. The reproducer recalculates every known usage price (rounded up per attempt to integer microdollars) and all 1/3/5-prefix sums. All five draws were executed and paid for. A single-pass context estimate divides five-draw test cost by five; prefix sample-budget estimates use the corresponding actual attempts. These are attributed inference estimates, not separately deployed policies, invoices, or project totals. Missing usage has an explicit conservative upper bound. Earlier abandoned preparation costs are separate aggregates in the method notes, outside these rows.

All arms used the same reviewed local workers with a loopback network guard, and Forge inference, Agent Lens and W&B telemetry. This is host execution, not cloud sandbox isolation. Exact native scorers stayed fixed. The task set had already been inspected in the earlier controls; this is a prospective engineering follow-up, not an untouched final evaluation. This public bundle reproduces calculations; it cannot regrade withheld answer text or independently establish that the labels are semantically right.
